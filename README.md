## 基本ルール

- 盤面は6列×10行
- 通常ブロックは4種類
- 上下左右に隣り合う2個を交換
- 交換は1回1手
- マッチしない交換も可能
- 縦または横に3個以上揃うと即時点火
- 発射・落下・連鎖は自動
- 基本3手ごとに下から1段せり上がる
- 揃う交換がない場合は自動で1段追加
- 上端から合計30個を打ち上げるとSTAGE CLEAR
- せり上がり時に上端のブロックが押し出されるとGAME OVER
- 考えている時間では盤面は進まない

## 採用しないもの

- 2×2回転
- 点火待ち
- 手動発射
- BOOST列
- PUSH
- 落下ブロックの列移動
- 連鎖途中の忙しいタイミング操作

## 面白さとして確認すること

1. 3個・4個・5個の推力差が分かりやすく、狙い分ける意味があるか
2. 上に乗るブロック数による重量ペナルティが直感的か
3. 自動連鎖を自分で狙った感覚が出るか
4. オススメが便利すぎて考える必要を消していないか
5. 上がりきらない発射でも爽快感が残っているか
6. 30個クリアまでの長さが適切か
7. 3手ごとのせり上がりが適切か


### ドラッグ操作

通常手番では、ブロックを押したまま上下または左右へドラッグするか、移動元と移動先を2回タップします。同じ行または列で連続してブロックが存在する範囲を隣接交換しながら移動し、空白は越えられません。**1回のドラッグ全体、または2回タップの移動全体で1手**として扱い、その後にマッチ・発射・追撃を解決します。
