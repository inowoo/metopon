# METOPON（メトポン／仮）

**「一手を選んで、あとは見守る」打ち上げ連鎖パズル。**

『メテオス』の打ち上げる爽快感と、『パネルでポン』の横入れ替え・せり上がる盤面を参考にしながら、忙しいリアルタイム操作をなくした独自のターン制パズルを目指します。

> このREADMEは、相談と試作を通じて更新していく企画・仕様書です。  
> まず小さな試作を作り、コアルールが本当に面白いかを検証します。

## 遊べる試作

**現在の試作バージョン：v0.6.1**

[index.html](./index.html) をブラウザで開くと、そのまま遊べます。ビルドやインストールは不要です。

現在の試作で遊べる内容：

- 6×10のターン制盤面
- 左右のブロック交換
- 縦横3マッチ
- マッチした列の自動打ち上げ
- 落下後の自動連鎖
- 基本3手ごとのせり上がり（大量打ち上げで延期可能）
- 一手戻し
- ヒント
- 1手だけ自動で進める「おまかせ」
- 自動処理の早送り
- ブラウザ内へのスコアと盤面の保存
- 上端から合計6個のブロックを打ち上げるとステージクリア
- 盤面上端到達でゲームオーバー
- 画面内に収まりやすいレスポンシブレイアウト
- ゆっくり確認できる交換・マッチ・打ち上げ・落下アニメーション
- マッチ成立時の発光・バーストエフェクト
- 揃ったブロック自身がロケットのように上端へ飛んでいく打ち上げ演出
- 揃ったブロックの上昇は通常速度で**1ドットずつ、間を置きながらゆっくり進む**
- 交換・打ち上げ・落下・せり上がりも通常速度では**1ステップ1px**で動かす
- 通常速度では移動座標を整数ピクセル単位で更新し、CSSの座標補間に任せない
- ステージルールを画面上に常時表示
- 打ち上げ後・落下前に盤面を止め、1個だけ左右の空きマスへ動かせる「連鎖介入」
- 介入は1手につき1回だけ
- 動かしたくない場合は「そのまま落下」でスキップ可能
- おまかせで最初の交換を自動化しても、連鎖介入はプレイヤー自身が行える

### 現在の実装範囲

現在の `v0.6.1` は、**1ステージ分のコアルールを検証するブラウザ試作**です。  
README後半には将来のMVP・パズルモード・技術構成案も残していますが、それらはすべて実装済みという意味ではありません。

現在実装済みなのは、主に次の範囲です。

- クリック／タップによる横交換
- 縦横3個以上のマッチ
- 3個=2マス、4個=4マス、5個以上=6マスのライン推力
- 複数ライン同時成立時の推力合算
- 横縦ラインが交差する十字／L字の追加+2マス
- 打ち上げ、上端からの除去、落下、自動連鎖

- 基本3手ごとのせり上がりと、大量打ち上げによる1手延期
- LAUNCH 6個でステージクリア
- 上端にブロックがある状態でせり上がるとゲームオーバー

## 2. ゲームの一言説明

盤面上のブロックを一組だけ横に入れ替え、同じ種類を縦か横に3個以上そろえます。

マッチが成立すると、点火、打ち上げ、除去、落下、次のマッチまでが**すべて自動で進行**します。  
プレイヤーは連鎖中に急いで操作する必要がありません。

盤面が完全に止まったら、次の一手をゆっくり考えます。

## 3. 基本コンセプト

### 考える場面と動く場面を分ける

ゲームは次の2つの状態を交互に繰り返します。

#### 思考フェーズ

- 盤面は完全に停止する
- せり上がりも時間も進まない
- プレイヤーは好きなだけ考えられる
- 交換候補を選ぶと結果の一部をプレビューできる
- 一組のブロックを横交換すると自動処理へ進む

#### 自動連鎖フェーズ

- マッチを自動判定する
- マッチした場所からブロックを打ち上げる
- 上端を越えたブロックを除去する
- **その手で最初の1回だけ、落下前に1ブロック横移動の介入を行える**
- 残ったブロックを落下させる
- 新しいマッチができたら自動で再点火する
- 以降の連鎖は自動処理する
- 盤面が安定したら思考フェーズへ戻る

現在の試作では、自動処理中に使える速度操作は**早送り**です。  
一時停止と演出全体のスキップは将来追加候補です。

## 4. このゲームで目指す面白さ

- 時間に追われず、次の一手を考えられる
- 一手を選ぶだけで連鎖が自動的に展開する
- 仕込んだ連鎖が予想どおり動く気持ちよさがある
- 予想以上の連鎖が起きる楽しさもある
- 大量のブロックが一気に上へ飛ぶ爽快感がある
- 「今すぐ小さく消す」か「数手かけて大きく飛ばす」かを選べる
- 操作量ではなく、盤面を見る力と一手の選択で上達できる

## 5. 盤面

- 盤面は仮に**横6マス × 縦10マス**
- 通常ブロックは最初は4種類
- ブロックは重力によって下へ落ちる
- ブロックは上方向へ打ち上げられる
- 上端の外へ飛び出したブロックは除去される
- 一定手数ごとに新しい1段が下から追加される

盤面サイズとブロック数は、スマートフォンでの見やすさと連鎖の作りやすさを確認して調整します。

## 6. プレイヤー操作

### 基本操作

現在の試作：

- ブロックをクリック／タップして選択
- 左右どちらかの隣接マスを選ぶと交換
- 空きマスとの交換も可能
- 縦方向には交換できない
- 1回の交換で1手を消費する

予定：

- 左右への短いドラッグ／スワイプでも交換できるようにする

マッチしない交換も可能です。  
すぐには消さず、次の手のために配置を整えることができます。

### 補助操作

- 一手戻す：現在の試作では直前の思考フェーズへ戻る
- リスタート：問題の初期状態へ戻る
- 早送り：自動連鎖の演出速度を上げる
- 演出スキップ：**未実装。将来追加候補**
- ヒント：マッチを作れる交換候補を1つ示す
- おまかせ：候補の中から単純な即時マッチを1手だけ自動実行する。操作時は「1個目を選択 → 交換先を選択 → 交換」の順に間を置いて見せ、交換後は**実際に揃ったブロック群を点滅表示して理由を説明する**

「おまかせ」は最適解を保証しません。  
考えるのが面倒な時や、盤面を少し動かしたい時の補助として使います。

## 7. マッチ

- 同じ種類のブロックを縦または横に3個以上そろえると点火
- 4個以上、十字、L字、複数ライン同時成立は強い点火になる
- プレイヤーの交換後、盤面全体のマッチを同時に判定する
- 落下や打ち上げの結果できたマッチも自動で点火する
- 自動点火が続くたびに連鎖数が増える

## 8. 打ち上げ

マッチしたブロックは、上のブロックを飛ばすための「噴射台」になります。

### 現在の試作ルール

1. マッチしたブロックが発光して点火する
2. **揃ったブロック自身がロケットのように上方向へ飛び、盤面上端の外へ抜ける**
3. ルール上は、そのマッチしたブロックは盤面から除去される
4. マッチした各マスの真上にあるブロック列を上へ押し上げる
5. 上端を越えたブロックは除去される
6. 届かなかったブロックは重力で落下する
7. 落下後に新しいマッチがあれば自動で再点火する

ロケット演出は「揃ったこと」と「上方向へ打ち上げるゲームであること」を視覚的に分かりやすくするための演出です。  
通常速度では、揃ったブロックは**ブラウザの描画フレームごとに現在座標を1pxずつ直接加減算して上昇**します。交換・列打ち上げ・落下・せり上がりも同じ方式です。`setTimeout` ではなく `requestAnimationFrame` を使い、通常速度では1描画フレームにつき最大1pxだけ進みます。早送り時だけ複数pxずつ進みます。

### 打ち上げる利点

現在の試作では、打ち上げは単なる演出ではなくゲームの主目的です。

- マッチによって上の列を押し上げ、**ブロックが盤面上端を越えた数を LAUNCH として数える**
- **LAUNCH が合計6個になると STAGE CLEAR**
- 1回の点火で**3個以上を上端から飛ばすと、次のせり上がりを1手延期**
- 上端から飛ばしたブロックは盤面から消えるため、ゲームオーバーの危険も直接減る
- 上端から飛ばしたブロックは通常のマッチより高い得点になる

なお、マッチした3個そのものがロケットとして飛んでいく演出は「点火」を見せるためのものです。  
LAUNCH カウントに入るのは、その点火によって**真上の列から実際に盤面上端を越えて飛び出したブロック**です。

### プレイヤー介入：落下前の1ブロック移動

おまかせだけで盤面が進んでしまわないよう、**1手につき1回、打ち上げ後・落下前に盤面を止め、ブロックを1個だけ左右へ動かせる**仕組みにします。

- 打ち上げ処理が終わったところで一時停止する
- 左右どちらかに空きマスがあるブロックを光らせる
- プレイヤーが動かしたいブロックを選ぶ
- 左右の空きマスのどちらかを選び、1マスだけ横へ移動する
- 移動後に重力落下を再開する
- 落下結果で3個以上揃えば、そのまま自動連鎖へ入る
- 動かしたくない場合は「そのまま落下」でスキップできる
- 介入できるのは1手につき最初の1回だけ。以降の連鎖は自動で進む
- 「おまかせ」で最初の交換を自動化しても、この連鎖介入はプレイヤー自身が判断できる

狙いは、単なる発射強化ではなく、**「この1個をずらしたから次の連鎖が起きた」**と感じられることです。


MVPでは、打ち上げ対象を**マッチしたマスの真上の列**に限定します。  
つながった塊全体を飛ばす方式より、どのブロックが動くか予測しやすいためです。

### 推力の仮仕様

| マッチ | 打ち上げ距離 |
| --- | ---: |
| 3個 | 2マス |
| 4個 | 4マス |
| 5個以上 | 6マス |
| 十字／L字 | 追加で2マス |
| 複数ライン同時 | 各ラインの推力を合算 |

最初は塊の重さによる減衰を入れません。  
「何個そろえると何マス上がるか」を見ただけで予測できることを優先します。

## 9. 自動連鎖

METOPONでは、連鎖中に忙しい操作を要求しません。  
ただし1手につき最初の1回だけ、打ち上げ後・落下前に「1ブロック横移動」の介入を行えます。

### 落下連鎖

マッチしたブロックが消え、残ったブロックが落下した結果、新しいマッチが成立します。

### 打ち上げ連鎖

列ごとの打ち上げ距離の違いによってブロックの高さが変わり、新しいマッチが成立します。

### 同時点火

一手で複数のマッチを成立させ、複数の列を同時に打ち上げます。

### 仕込み連鎖

数手かけてブロックを配置し、最後の一手から複数回の自動連鎖を発生させます。

連鎖が始まったあとは、マッチがなくなって盤面が安定するまで自動で解決します。

## 10. 一手の流れ

1. 盤面が停止し、思考フェーズになる
2. プレイヤーが交換する2個を選ぶ
3. 交換結果と、最初に点火する場所を短く表示する
4. 交換を実行して1手消費する
5. 全マッチを同時に判定する
6. マッチしたブロックを点火する
7. 対象列と推力を確定する
8. ブロックを打ち上げる
9. 上端を越えたブロックを除去する
10. その手でまだ介入していなければ、落下前に1個だけ左右へ動かすか「そのまま落下」を選ぶ
11. 残ったブロックを落下させる
12. 新しいマッチがあれば、連鎖数を増やして手順5へ戻る
13. マッチがなければ盤面を安定させる
14. 規定手数に達していれば新しい1段を追加する
15. 追加後の自動マッチも最後まで処理する
16. 次の思考フェーズへ戻る

打ち上げ・落下・連鎖そのものは、同じ盤面・同じ交換・同じ介入選択なら同じ結果になるようにします。  
ただし現在の試作では、新しい段の生成と手詰まりシャッフルに乱数を使うため、ゲーム全体はまだ完全な決定論にはなっていません。将来のパズルモードでは固定ステージデータを使います。

## 11. せり上がり

リアルタイムではせり上がりません。

- 基本は**3手ごと**に新しい1段を追加する
- 次にせり上がるまでの残り手数を常に表示する
- 自動連鎖中には段を追加しない
- **1回の点火で3個以上を上端から飛ばすと、次のせり上がりを1手遅らせる**
- 1手の中で延期ボーナスを得られるのは最大1回
- 手詰まりの場合は、ペナルティなしで自動シャッフルする

### ステージクリア

現在の試作では、**マッチの推力によって盤面上端から合計6個のブロックを飛ばすと、その打ち上げ演出が終わった時点で STAGE CLEAR** です。  
6個目を飛ばした後に追加の介入や落下操作は要求しません。画面上部の LAUNCH に現在数／目標数を表示し、盤面下にもクリア条件を常時表示します。

スコアは記録用として残しますが、現在のクリア条件には使いません。  
今後パズルモードを追加した後は、「指定数を打ち上げる」「指定連鎖を作る」など、ステージごとに異なる条件を持たせます。

### ゲームオーバー

**3手ごとのせり上がりが発生する時、すでに最上段にブロックが残っていて、そのブロックが盤面外へ押し出される状態なら GAME OVER** です。

つまり、考えている時間や単なる時間経過ではゲームオーバーになりません。  
危険なのは「次のせり上がりまでに上端を空けられるか」です。

## 13. ゲームモード

### 13.1 パズルモード（未実装・次の大きな目標）

決められた盤面を、指定条件で解くモードです。  
現在のv0.6.1には固定ステージ選択やステージJSON読み込みはまだありません。

条件の例：

- 3手以内にすべてのブロックを飛ばす
- 1回の点火で10個以上飛ばす
- 3連鎖を発生させる
- 指定されたブロックをすべて除去する
- せり上がる前に盤面を指定の高さ以下にする

時間制限はなく、一手戻しとリスタートをいつでも使えます。

### 13.2 のんびり継続モード（将来案）

ゲームオーバーまでスコアを伸ばすターン制モードです。現在の試作はLAUNCH 6個で終了するため、この継続モードそのものではありません。

- 3手ごとに1段せり上がる
- レベルが上がるとブロック種類や初期配置が変化する
- 時間経過では難しくならない
- 長く考えても不利にならない
- ハイスコアをブラウザに保存する
- 好きなところで中断し、後から再開できる

### 13.3 今日の問題（将来案）

毎日1問を提供します。  
手数、連鎖数、打ち上げ数で結果を比較できますが、時間は評価に使いません。

## 14. 得点と評価

### 現在の試作

現在の得点は、

- マッチしたブロック数
- 上端から飛ばしたブロック数
- 連鎖数

を使って計算します。

### 将来の評価候補

- 同時点火したライン数
- 一手で動いたブロックの総数

パズルモードの評価候補：

- クリア：条件を達成
- 星2：目標手数以内
- 星3：最少手数、または指定連鎖数を達成

クリアそのものを優先し、最短手数を強制しません。

## 15. 問題生成と検証

AIや自動生成器に盤面候補を作らせ、ゲームと同じルールを使うソルバーで正しさを検証します。

### 生成手順

1. 目的、盤面サイズ、難易度を指定する
2. AIまたは生成器が盤面候補を作る
3. ソルバーが可能な横交換を探索する
4. 各交換後の自動連鎖を最後まで計算する
5. 解けること、最短手数、解答数を確認する
6. 簡単すぎる別解や不要なブロックを調べる
7. 条件を満たす問題だけ採用する
8. 最後に人間が遊んで面白さを確認する

### 自動検証する項目

- 初期状態で意図しないマッチがない
- 指定手数以内に解ける
- 自動連鎖が必ず終了する
- 同じ入力から同じ結果になる
- 操作不能な状態にならない
- 偶然だけで解ける問題に偏らない
- 同型の問題が重複しない

AIは問題案を作る役、ソルバーは正しさを保証する役とします。

## 16. ブロックの種類

MVPでは通常ブロック4種類から開始します。

| 種類 | 見分け方 |
| --- | --- |
| 1 | 色＋丸 |
| 2 | 色＋三角 |
| 3 | 色＋四角 |
| 4 | 色＋星 |

難易度を上げる段階で5種類目の「色＋波線」を追加します。

色だけで区別せず、形と模様を必ず併用します。  
危険表示も赤色だけに頼らず、枠の形、点滅、アイコンで伝えます。

### 将来追加する候補

- おじゃまブロック：隣接する点火で通常ブロックに変わる
- 重量ブロック：複数回の打ち上げが必要
- ワイルドブロック：隣接する種類として扱う
- 固定ブロック：一度点火させると交換可能になる

特殊ブロックは、通常ブロックだけで面白いことを確認してから追加します。

## 17. 見た目と音

### ビジュアル

- 明るい宇宙工場、または抽象的な発射装置を仮テーマにする
- 小さな画面でもブロックを判別できる形にする
- 思考フェーズでは盤面を静かに表示する
- 選択時は、交換先、点火位置、打ち上げ列を順に表示する
- 自動連鎖中は、原因と結果を目で追える速度にする
- 大量打ち上げだけは派手に演出する
- 早送り時も現在の連鎖数を見失わないようにする

### サウンド

- 交換、点火、打ち上げ、着地、上端からの射出を別の音にする
- 連鎖ごとに音程と厚みを少し上げる
- 思考中に急かす音を鳴らさない
- 音を消しても視覚情報だけで遊べるようにする

### 構成方針

ゲームルールと表示を分離します。

```text
GameState
├─ Board             盤面データ
├─ TurnSystem        手数と段の追加
├─ SwapSystem        横交換
├─ MatchSystem       マッチ判定
├─ LaunchSystem      列の打ち上げ
├─ GravitySystem     落下
├─ ChainResolver     自動連鎖
├─ AssistSystem      ヒントとおまかせ
└─ ScoreSystem       得点と評価

Renderer             描画と演出
InputController      マウス／タッチ
PuzzleSolver         問題の探索と検証
```

内部では整数のマス座標で結果を先に計算し、表示側がその結果を順にアニメーションします。  
これにより、早送りやスキップをしてもゲーム結果が変わりません。

## 24. 現在の決定事項

- 『メテオス』と『パネルでポン』を参考にする
- 忙しいリアルタイム操作は入れない
- 考える時間に制限を設けない
- プレイヤーの通常操作は横交換。加えて1手につき1回だけ落下前介入を行える
- 一手のあとは、打ち上げ後・落下前に1ブロック横移動の介入を1回だけ行える
- 介入後の落下、再点火、連鎖は自動処理する
- 自動連鎖中に忙しい操作は要求しない
- せり上がりは時間ではなく手数で進む
- 1回で3個以上を上端から飛ばすと、次のせり上がりを1手延期する
- 現在のステージクリア条件は、上端から合計6個を打ち上げること
- マッチしたブロックはルール上は除去し、演出ではロケットのように上端へ飛ばす
- LAUNCHとして数えるのは、推力で真上の列から実際に上端を越えたブロック
- 打ち上げ対象は、まず真上の列だけにする
- ブラウザでマウス／タッチだけで遊べる
- 色以外の形や模様でもブロックを区別する
- まずパズルモードを完成させる
- 問題生成を導入する場合はソルバーで必ず検証する
- 参考作品の素材、名称、画面、ルールをそのまま複製せず、独自の手触りを作る
