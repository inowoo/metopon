# METOPON（メトポン／仮）

**「一手を選ぶと、盤面が大きく動く」ターン制・打ち上げ連鎖パズル。**

『メテオス』の上方向へ飛ばす爽快感と、『パネルでポン』のブロック交換・せり上がる盤面を参考にしつつ、忙しいリアルタイム操作をなくした独自ルールを試作しています。

## 現在の試作

**main：v0.8.0 実験版**

[index.html](./index.html) をブラウザで開くと遊べます。

### 保存してある基準版

**basic01** ブランチは、余計な追加ルールを入れる前のベーシック版です。

- 上下左右の隣接交換
- 3マッチ
- 即時自動発射
- 自動落下・自動連鎖
- 2×2回転なし
- 点火待ちなし
- 発射ボタンなし
- おすすめ2個表示なし

実験が面白くなければ、basic01を基準に戻して別案を試せます。

## v0.8.0で試すこと

basic01では「3個揃えれば結果が大きく動く」一方、**どこで何個揃えるかの差が薄い**ため、v0.8.0では交換の選び方に意味を増やします。

### 1. マッチ数で打ち上げ推力が変わる

| マッチ | 推力 |
| --- | ---: |
| 3個 | 2マス |
| 4個 | 4マス |
| 5個以上 | 6マス |

揃ったブロック自身はロケットとして盤面上端へ飛びます。

その上にあるブロックは推力ぶんだけ上へ押し上げられ、上端を越えたものもLAUNCHとして数えます。

これにより、

- すぐ3個を作る
- 1手余計に使って4個を狙う
- 5個以上の大打ち上げを狙う

という選択を作ります。

### 2. BOOST列

毎ターン、6列のうち1列が**BOOST列**になります。

- BOOST列は盤面上で光って表示される
- BOOST列でマッチすると、その列だけ**推力+2**
- BOOST列はターン終了時に別の列へ移動する

追加操作はありません。

「今すぐ揃えるか」「BOOST列側で揃えるか」という盤面判断だけを増やします。

### 3. BIG / CHAIN BONUS

次のどちらかを達成すると、次のせり上がりを1手延期します。

- 4個以上を揃える
- 2連鎖以上を起こす

普通の3マッチを繰り返すだけより、少し欲張った手に価値を持たせます。

### 4. クロス成立

縦横が交差するマッチはCROSSとして扱い、追加得点を与えます。

交差した列は推力も追加されます。

## 基本ルール

- 盤面は6列×10行
- 通常ブロックは4種類
- 上下左右に隣り合う2個を交換
- 交換は1回1手
- マッチしない交換も可能
- 縦または横に3個以上揃うと即時点火
- 発射・落下・連鎖は自動
- 基本3手ごとに下から1段せり上がる
- 揃う交換がない場合は自動で1段追加
- 上端から合計30個を打ち上げるとSTAGE CLEAR
- せり上がり時に上端のブロックが押し出されるとGAME OVER
- 考えている時間では盤面は進まない

## プレイヤーに要求しないこと

- リアルタイムの忙しい操作
- 2×2回転
- 点火待ち
- 手動発射
- 連鎖途中のタイミング入力
- 「この2個がおすすめ」という答え表示

## 面白さとして確認すること

1. 3個・4個・5個のどれを狙うか迷えるか
2. BOOST列が押し付けにならず、自然な目標になるか
3. 4個以上を仕込む価値が分かりやすいか
4. 自動連鎖が偶然だけでなく「狙った」と感じられるか
5. 推力が小さくなったことで盤面の変化が弱すぎないか
6. 30個クリアまでの長さが適切か
7. 3手ごとのせり上がりが厳しすぎないか
