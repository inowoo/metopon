## v0.8.10で試すこと

### 1. 推力と重量

発射は「必ず上端まで飛ぶ」方式をやめ、**揃った数＝推力、上に乗っているブロック＝重量**で上昇距離を決めます。

| マッチ | 基礎推力 |
|---|---:|
| 3個 | 2 |
| 4個 | 4 |
| 5個以上 | 6 |

その列のマッチより上にあるブロック**1個ごとに実効推力-1**。最低でも1マスは上昇します。

例：
- 3個揃い、上に0個 → 2マス上昇
- 3個揃い、上に1個 → 1マス上昇
- 4個揃い、上に2個 → 2マス上昇
- 5個揃い、上に3個 → 3マス上昇

揃ったブロックは推力源として同じ距離だけ上昇し、到達点で燃焼します。上に乗っていたブロックは実効推力ぶんだけ上昇し、上端を越えなければ盤面に残ります。**上端を越えたブロックだけをLAUNCH数として数えます。**

これにより盤面が一度に空きすぎず、4個・5個を狙う意味と追撃の余地を作ります。

### 2. BIG / CHAIN BONUS

次のどちらかを達成すると、次のせり上がりを1手延期します。

- 4個以上を揃える
- 2連鎖以上を起こす

### 3. CROSS

縦横が交差するマッチはCROSSとして扱います。

- 交差した列の推力+2
- 追加得点

### 4. オススメボタン

**「オススメ」ボタンを押した時だけ**、現在の盤面から良さそうな交換1手を表示します。

- 交換する2マスは同じ白枠で強調する
- ①②などの数字は表示しない
- 常時表示はしない
- プレイヤーが別のマスを触ると表示は解除
- 主に、どこを動かせばよいか分からなくなった時の補助として使う

候補は、直接打ち上げられる個数、大きいマッチ、CROSS、マッチ数を基準に選びます。

### 5. 追撃交換

v0.8.10では、iPhoneで盤面が黒く見える問題を修正しました。追撃時に盤面全体へfilter/opacityをかけず、通常表示を保ったまま候補だけ枠で強調します。

自然な自動連鎖が途切れた時に、**実際に3個以上を作れる交換がある場合だけ**追撃チャンスが発生します。

- 追撃可能な交換に関係する**実ブロック**だけ黄色枠で強調する（空マスは候補にしない）
- 1個選ぶと、そのブロックと交換してマッチを作れる相手だけ白く光る
- 白く光った相手を選ぶと追撃交換
- 揃わない交換は追撃では受け付けない
- 追撃で揃えば、同じ手番の連鎖として追加発射
- 「追撃しない」を選べばそのまま手番終了
- 追撃は1手番につき最大1回

盤面が以前より残るため、発射後に「どこをもう一手動かせば連鎖になるか」を考える意味が増えます。

## 基本ルール

- 盤面は6列×10行
- 通常ブロックは4種類
- 上下左右に隣り合う2個を交換
- 交換は1回1手
- マッチしない交換も可能
- 縦または横に3個以上揃うと即時点火
- 発射・落下・連鎖は自動
- 基本3手ごとに下から1段せり上がる
- 揃う交換がない場合は自動で1段追加
- 上端から合計40個を打ち上げるとSTAGE CLEAR
- せり上がり時に上端のブロックが押し出されるとGAME OVER
- 考えている時間では盤面は進まない

## 採用しないもの

- 2×2回転
- 点火待ち
- 手動発射
- BOOST列
- PUSH
- 落下ブロックの列移動
- 連鎖途中の忙しいタイミング操作

## 面白さとして確認すること

1. 3個・4個・5個の推力差が分かりやすく、狙い分ける意味があるか
2. 上に乗るブロック数による重量ペナルティが直感的か
3. 自動連鎖を自分で狙った感覚が出るか
4. オススメが便利すぎて考える必要を消していないか
5. 上がりきらない発射でも爽快感が残っているか
6. 40個クリアまでの長さが適切か
7. 3手ごとのせり上がりが適切か
