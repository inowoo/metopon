# METOPON（メトポン／仮）

**「一手を選んで、あとは見守る」打ち上げ連鎖パズル。**

『メテオス』の打ち上げる爽快感と、『パネルでポン』の横入れ替え・せり上がる盤面を参考にしながら、忙しいリアルタイム操作をなくした独自のターン制パズルを目指します。

> このREADMEは、相談と試作を通じて更新していく企画・仕様書です。  
> まず小さな試作を作り、コアルールが本当に面白いかを検証します。

## 遊べる試作

[index.html](./index.html) をブラウザで開くと、そのまま遊べます。ビルドやインストールは不要です。

現在の試作で遊べる内容：

- 6×10のターン制盤面
- 左右のブロック交換
- 縦横3マッチ
- マッチした列の自動打ち上げ
- 落下後の自動連鎖
- 3手ごとのせり上がり
- 一手戻し
- ヒント
- 1手だけ自動で進める「おまかせ」
- 自動処理の早送り
- ブラウザ内へのスコアと盤面の保存


## 1. 企画概要

| 項目 | 内容 |

## 2. ゲームの一言説明

盤面上のブロックを一組だけ横に入れ替え、同じ種類を縦か横に3個以上そろえます。

マッチが成立すると、点火、打ち上げ、除去、落下、次のマッチまでが**すべて自動で進行**します。  
プレイヤーは連鎖中に急いで操作する必要がありません。

盤面が完全に止まったら、次の一手をゆっくり考えます。

## 3. 基本コンセプト

### 考える場面と動く場面を分ける

ゲームは次の2つの状態を交互に繰り返します。

#### 思考フェーズ

- 盤面は完全に停止する
- せり上がりも時間も進まない
- プレイヤーは好きなだけ考えられる
- 交換候補を選ぶと結果の一部をプレビューできる
- 一組のブロックを横交換すると自動処理へ進む

#### 自動連鎖フェーズ

- マッチを自動判定する
- マッチした場所からブロックを打ち上げる
- 上端を越えたブロックを除去する
- 残ったブロックを落下させる
- 新しいマッチができたら自動で再点火する
- マッチがなくなるまで自動処理を繰り返す
- 盤面が安定したら思考フェーズへ戻る

自動連鎖フェーズ中は操作を要求しません。  
演出を見守るだけでよく、いつでも一時停止、早送り、演出スキップができます。

## 4. このゲームで目指す面白さ

- 時間に追われず、次の一手を考えられる
- 一手を選ぶだけで連鎖が自動的に展開する
- 仕込んだ連鎖が予想どおり動く気持ちよさがある
- 予想以上の連鎖が起きる楽しさもある
- 大量のブロックが一気に上へ飛ぶ爽快感がある
- 「今すぐ小さく消す」か「数手かけて大きく飛ばす」かを選べる
- 操作量ではなく、盤面を見る力と一手の選択で上達できる

## 5. 盤面

- 盤面は仮に**横6マス × 縦10マス**
- 通常ブロックは最初は4種類
- ブロックは重力によって下へ落ちる
- ブロックは上方向へ打ち上げられる
- 上端の外へ飛び出したブロックは除去される
- 一定手数ごとに新しい1段が下から追加される

盤面サイズとブロック数は、スマートフォンでの見やすさと連鎖の作りやすさを確認して調整します。

## 6. プレイヤー操作

### 基本操作

- ブロックをクリック／タップして選択
- 左右どちらかの隣接ブロックを選ぶと交換
- または、左右への短いドラッグ／スワイプで交換
- 空きマスとの交換も可能
- 縦方向には交換できない
- 1回の交換で1手を消費する

マッチしない交換も可能です。  
すぐには消さず、次の手のために配置を整えることができます。

### 補助操作

- 一手戻す：パズルモードでは直前の思考フェーズへ戻る
- リスタート：問題の初期状態へ戻る
- 早送り：自動連鎖の演出速度を上げる
- スキップ：自動処理の最終結果まで進める
- ヒント：マッチを作れる交換候補を1つ示す
- おまかせ：候補の中から単純な即時マッチを1手だけ自動実行する

「おまかせ」は最適解を保証しません。  
考えるのが面倒な時や、盤面を少し動かしたい時の補助として使います。

## 7. マッチ

- 同じ種類のブロックを縦または横に3個以上そろえると点火
- 4個以上、十字、L字、複数ライン同時成立は強い点火になる
- プレイヤーの交換後、盤面全体のマッチを同時に判定する
- 落下や打ち上げの結果できたマッチも自動で点火する
- 自動点火が続くたびに連鎖数が増える

## 8. 打ち上げ

マッチしたブロックは、上のブロックを飛ばすための「噴射台」になります。

### 仮ルール

1. マッチしたブロックが点火する
2. マッチしたブロックはエネルギーに変わって消える
3. マッチした各マスの真上にあるブロック列を上へ押し上げる
4. 上端を越えたブロックは除去される
5. 届かなかったブロックは落下する
6. 落下後にマッチがあれば自動で再点火する

MVPでは、打ち上げ対象を**マッチしたマスの真上の列**に限定します。  
つながった塊全体を飛ばす方式より、どのブロックが動くか予測しやすいためです。

### 推力の仮仕様

| マッチ | 打ち上げ距離 |
| --- | ---: |
| 3個 | 2マス |
| 4個 | 4マス |
| 5個以上 | 6マス |
| 十字／L字 | 追加で2マス |
| 複数ライン同時 | 各ラインの推力を合算 |

最初は塊の重さによる減衰を入れません。  
「何個そろえると何マス上がるか」を見ただけで予測できることを優先します。

## 9. 自動連鎖

METOPONでは、連鎖中にプレイヤー操作を要求しません。

### 落下連鎖

マッチしたブロックが消え、残ったブロックが落下した結果、新しいマッチが成立します。

### 打ち上げ連鎖

列ごとの打ち上げ距離の違いによってブロックの高さが変わり、新しいマッチが成立します。

### 同時点火

一手で複数のマッチを成立させ、複数の列を同時に打ち上げます。

### 仕込み連鎖

数手かけてブロックを配置し、最後の一手から複数回の自動連鎖を発生させます。

連鎖が始まったあとは、マッチがなくなって盤面が安定するまで自動で解決します。

## 10. 一手の流れ

1. 盤面が停止し、思考フェーズになる
2. プレイヤーが交換する2個を選ぶ
3. 交換結果と、最初に点火する場所を短く表示する
4. 交換を実行して1手消費する
5. 全マッチを同時に判定する
6. マッチしたブロックを点火する
7. 対象列と推力を確定する
8. ブロックを打ち上げる
9. 上端を越えたブロックを除去する
10. 残ったブロックを落下させる
11. 新しいマッチがあれば、連鎖数を増やして手順5へ戻る
12. マッチがなければ盤面を安定させる
13. 規定手数に達していれば新しい1段を追加する
14. 追加後の自動マッチも最後まで処理する
15. 次の思考フェーズへ戻る

同じ盤面と同じ一手からは、必ず同じ結果になるようにします。

## 11. せり上がり

リアルタイムではせり上がりません。

- 仮に**3手ごと**に新しい1段を追加する
- 次にせり上がるまでの残り手数を常に表示する
- 自動連鎖中には段を追加しない
- 大きな連鎖を作ると、次のせり上がりを1手遅らせるボーナスを検討する
- 手詰まりの場合は、ペナルティなしで自動シャッフルする

### ゲームオーバー

新しい段を追加した結果、ブロックが盤面上端を越える場合にゲームオーバーです。

追加前には「次の手のあとにせり上がる」と明確に警告します。  
時間切れで突然終了することはありません。

## 12. アシスト機能

忙しくなく、詰まりにくいゲームにするため、次の補助を用意します。

### 常時表示

- 次の段が追加されるまでの残り手数
- 現在の最大高さ
- 交換可能な場所
- 選択中の交換で発生する最初のマッチ
- 打ち上げられる列と、おおよその到達位置

### 任意で使える補助

- マッチ可能な手のハイライト
- 連鎖が起きる可能性のある手のヒント
- 一手戻す
- 自動連鎖の早送り
- 演出スキップ
- 即時マッチを1回行う「おまかせ」
- 手詰まり時の自動シャッフル

ヒントやおまかせを使ってもステージクリアは可能にします。  
高評価だけを狙いたい場合に、使用回数を評価へ反映する案を検討します。

## 13. ゲームモード

### 13.1 パズルモード

決められた盤面を、指定条件で解くモードです。  
まずこのモードを完成させます。

条件の例：

- 3手以内にすべてのブロックを飛ばす
- 1回の点火で10個以上飛ばす
- 3連鎖を発生させる
- 指定されたブロックをすべて除去する
- せり上がる前に盤面を指定の高さ以下にする

時間制限はなく、一手戻しとリスタートをいつでも使えます。

### 13.2 のんびり継続モード

ゲームオーバーまでスコアを伸ばすターン制モードです。

- 3手ごとに1段せり上がる
- レベルが上がるとブロック種類や初期配置が変化する
- 時間経過では難しくならない
- 長く考えても不利にならない
- ハイスコアをブラウザに保存する
- 好きなところで中断し、後から再開できる

### 13.3 今日の問題（将来案）

毎日1問を提供します。  
手数、連鎖数、打ち上げ数で結果を比較できますが、時間は評価に使いません。

## 14. 得点と評価

基本得点は次の要素から計算します。

- マッチしたブロック数
- 上端から飛ばしたブロック数
- 自動連鎖数
- 同時点火したライン数
- 一手で動いたブロックの総数

パズルモードの評価候補：

- クリア：条件を達成
- 星2：目標手数以内
- 星3：最少手数、または指定連鎖数を達成

クリアそのものを優先し、最短手数を強制しません。

## 15. 問題生成と検証

AIや自動生成器に盤面候補を作らせ、ゲームと同じルールを使うソルバーで正しさを検証します。

### 生成手順

1. 目的、盤面サイズ、難易度を指定する
2. AIまたは生成器が盤面候補を作る
3. ソルバーが可能な横交換を探索する
4. 各交換後の自動連鎖を最後まで計算する
5. 解けること、最短手数、解答数を確認する
6. 簡単すぎる別解や不要なブロックを調べる
7. 条件を満たす問題だけ採用する
8. 最後に人間が遊んで面白さを確認する

### 自動検証する項目

- 初期状態で意図しないマッチがない
- 指定手数以内に解ける
- 自動連鎖が必ず終了する
- 同じ入力から同じ結果になる
- 操作不能な状態にならない
- 偶然だけで解ける問題に偏らない
- 同型の問題が重複しない

AIは問題案を作る役、ソルバーは正しさを保証する役とします。

## 16. ブロックの種類

MVPでは通常ブロック4種類から開始します。

| 種類 | 見分け方 |
| --- | --- |
| 1 | 色＋丸 |
| 2 | 色＋三角 |
| 3 | 色＋四角 |
| 4 | 色＋星 |

難易度を上げる段階で5種類目の「色＋波線」を追加します。

色だけで区別せず、形と模様を必ず併用します。  
危険表示も赤色だけに頼らず、枠の形、点滅、アイコンで伝えます。

### 将来追加する候補

- おじゃまブロック：隣接する点火で通常ブロックに変わる
- 重量ブロック：複数回の打ち上げが必要
- ワイルドブロック：隣接する種類として扱う
- 固定ブロック：一度点火させると交換可能になる

特殊ブロックは、通常ブロックだけで面白いことを確認してから追加します。

## 17. 見た目と音

### ビジュアル

- 明るい宇宙工場、または抽象的な発射装置を仮テーマにする
- 小さな画面でもブロックを判別できる形にする
- 思考フェーズでは盤面を静かに表示する
- 選択時は、交換先、点火位置、打ち上げ列を順に表示する
- 自動連鎖中は、原因と結果を目で追える速度にする
- 大量打ち上げだけは派手に演出する
- 早送り時も現在の連鎖数を見失わないようにする

### サウンド

- 交換、点火、打ち上げ、着地、上端からの射出を別の音にする
- 連鎖ごとに音程と厚みを少し上げる
- 思考中に急かす音を鳴らさない
- 音を消しても視覚情報だけで遊べるようにする

## 18. 技術案

- TypeScript
- HTML / CSS
- Canvas 2D
- Vite
- Vitest
- ステージデータはJSON
- GitHub Pagesで公開

### 構成方針

ゲームルールと表示を分離します。

```text
GameState
├─ Board             盤面データ
├─ TurnSystem        手数と段の追加
├─ SwapSystem        横交換
├─ MatchSystem       マッチ判定
├─ LaunchSystem      列の打ち上げ
├─ GravitySystem     落下
├─ ChainResolver     自動連鎖
├─ AssistSystem      ヒントとおまかせ
└─ ScoreSystem       得点と評価

Renderer             描画と演出
InputController      マウス／タッチ
PuzzleSolver         問題の探索と検証
```

内部では整数のマス座標で結果を先に計算し、表示側がその結果を順にアニメーションします。  
これにより、早送りやスキップをしてもゲーム結果が変わりません。

## 21. 最初に検証すること

1. 一手を選んだあと自動で結果が展開するだけで面白いか
2. 打ち上げられる列と到達位置を事前に理解できるか
3. 自動連鎖を見ている時間が長すぎないか
