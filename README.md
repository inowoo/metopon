## v0.8.2で試すこと

### 1. マッチ数で打ち上げ推力が変わる

| マッチ | 推力 |
| --- | ---: |
| 3個 | 2マス |
| 4個 | 4マス |
| 5個以上 | 6マス |

揃ったブロックと、その上に乗っているブロックは**同じ推力ぶん一緒に上昇**します。

揃ったブロックは上昇演出後に消えます。上に乗っていたブロックは移動先に残り、上端を越えたものはLAUNCHとして数えます。揃ったブロックが上のブロックを追い越して飛ぶことはありません。

狙いは、

- すぐ3個を作る
- 4個を作って強く飛ばす
- 5個以上の大打ち上げを狙う

という違いを作ることです。

### 2. BIG / CHAIN BONUS

次のどちらかを達成すると、次のせり上がりを1手延期します。

- 4個以上を揃える
- 2連鎖以上を起こす

### 3. CROSS

縦横が交差するマッチはCROSSとして扱います。

- 交差した列の推力+2
- 追加得点

### 4. オススメボタン

**「オススメ」ボタンを押した時だけ**、現在の盤面から良さそうな交換1手を表示します。

- 交換する2マスを①②で強調する
- 常時表示はしない
- プレイヤーが別のマスを触ると表示は解除
- 主に、どこを動かせばよいか分からなくなった時の補助として使う

候補は、直接打ち上げられる個数、大きいマッチ、CROSS、マッチ数を基準に選びます。

## 基本ルール

- 盤面は6列×10行
- 通常ブロックは4種類
- 上下左右に隣り合う2個を交換
- 交換は1回1手
- マッチしない交換も可能
- 縦または横に3個以上揃うと即時点火
- 発射・落下・連鎖は自動
- 基本3手ごとに下から1段せり上がる
- 揃う交換がない場合は自動で1段追加
- 上端から合計30個を打ち上げるとSTAGE CLEAR
- せり上がり時に上端のブロックが押し出されるとGAME OVER
- 考えている時間では盤面は進まない

## 採用しないもの

- 2×2回転
- 点火待ち
- 手動発射
- BOOST列
- 連鎖途中の忙しいタイミング操作

## 面白さとして確認すること

1. 3個・4個・5個のどれを狙うか迷えるか
2. 4個以上を仕込む価値が分かりやすいか
3. 自動連鎖を自分で狙った感覚が出るか
4. オススメが便利すぎて考える必要を消していないか
5. 推力が小さくなったことで爽快感が弱すぎないか
6. 30個クリアまでの長さが適切か
7. 3手ごとのせり上がりが適切か
